## โจทย์
โปรแกรมทํางานโดยใช้ Thread ควบคุมการเคลื่อนที่ของอุกกาบาตแต่ละลูกแยกกันอย่างอิสระ
- สามารถระบุจํานวนของอุกกาบาตที่จะใช้ในการจําลองได้โดยไม่แก้ Code (1 คะแนน)
- อุกกาบาตเคลื่อนที่ “แนวตรง” ไม่ว่าจะเป็น แนวตั้ง แนวนอน หรือแนวทะแยง (3 คะแนน)
- อุกกาบาตแต่ละลูกเคลื่อนที่เริ่มต้น ด้วยความเร็วที่ไม่เท่ากัน (1 คะแนน)
- อุกกาบาตเคลื่อนที่ชนขอบกาแลคซี (เฟรม) จะมีการเปลี่ยนทิศทางการเคลื่อนที่และมึความเร็วเพิ่มขึ้น (2 คะแนน)
- อุกกาบาตเคลื่อนที่ชนอุกกาบาตลูกอื่น อุกกาบาตลูกที่ลูกใดลูกหนึ่งจะระเบิดหายไป อุกกาบาตที่ไม่ระเบิดจะไม่เปลี่ยนทิศทางการเคลื่อนที่ (3 คะแนน)
- ไม่อนุญาตให้ใช้ AI ช่วยเขียน หากใช้ AI ช่วยเขียนมาและตอบไม่ได้ลดคะแนนที่ได้ลงครึ่งหนึ่ง
- ไม่อนุญาตให้ใช้ Timer และ ต้องเขียนเป็น Thread แยกกัน ไม่ใช่ใช้ Thread ตัวเดียวทั้งโปรแกรม
- การ Demo จะมีการแบ่ง % การทํางานของแต่ละคนในกลุ่มด้วย
